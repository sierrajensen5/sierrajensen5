JavaScript Flappy Bird Game

Welcome to the JavaScript Game page!

I made this game for my Web Fundamentals class using the W3 Schools JavaScript Tutorial, which is inspired by the Flappy Bird Game!

Have you heard of that game? Well here is my version!

I enhanced the game by adding CSS, adding a new background to the game, and by making it larger.

Do you want to give this game a try? Look at the instructions down below!

(This game works for both Computer & Mobile users. Don't believe me? Give it a try!)

How to Play

To play the game, use the "FLAP WINGS" button to move Up and Down.

Click the "PLAY AGAIN" button to play again.

How long will you last? Play to find out!

Thank you for playing my game!
